# 📈 Financial Sentiment Analysis Platform

An AI-powered financial analytics platform that analyzes financial news sentiment using NLP and compares sentiment trends with stock market movements.

The project uses **FinBERT (Financial Bidirectional Encoder Representations from Transformers)** to classify financial text sentiment and provides interactive visual insights.

---

## 🚀 Features

✅ Financial news sentiment analysis using FinBERT  
✅ Positive, Negative, and Neutral sentiment classification  
✅ Stock market trend visualization  
✅ Interactive analytics dashboard  
✅ Financial data preprocessing pipeline  
✅ Sentiment comparison with market movements  
✅ Data visualization using Plotly

## ⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/rishiksimon/financial-sentiment-platform.git

## Navigate to the project folder:

cd financial-sentiment-platform

## Install dependencies:

pip install -r requirements.txt

## Run the application:

streamlit run dashboard.py
